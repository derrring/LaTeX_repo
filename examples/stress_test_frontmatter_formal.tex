\chapter{What this sample verifies}

\begin{enumerate}
  \item \texttt{\textbackslash makefrontmatter} renders a full title
        page with institution at top, title (centered, LARGE), subtitle
        in small caps below, two authors with superscript email markers
        and address lines, location ``Yokohama...'' near the bottom,
        date, then a horizontal rule and the email directory in
        \texttt{\textbackslash texttt} font.
  \item \texttt{\textbackslash makededication} produces a separate page
        with italic right-aligned dedication ~30\% down.
  \item \texttt{\textbackslash makeabstract} produces \emph{two} pages
        (one per \texttt{\textbackslash setabstract} call); the second
        carries the overridden ``R\'esum\'e'' heading.
  \item \texttt{\textbackslash makeacknowledgements} produces one page.
  \item \texttt{\textbackslash makebackmatter} at end of document
        renders the colophon: ``Anderson, Bauer: \emph{Frontmatter
        Stress Test (formal variant)}, \copyright\ \the\year''.
  \item PDF metadata: open the PDF info dialog -- pdftitle should be
        the override string (\texttt{\textbackslash pdftitle}),
        pdfauthor should list ``Alice Anderson, Bob Bauer'',
        pdfsubject should be the subtitle text, pdfkeywords as set.
  \item Bob's affiliation uses \texttt{\textbackslash affilbreak} for
        tight two-line formatting.
\end{enumerate}
