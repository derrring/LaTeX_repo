\maketitle

\section{What this sample verifies}

\begin{enumerate}
  \item Four authors render in stacked layout, each with optional
        thanks-footnote (email) and italic small-text address below.
  \item Carol's slot has empty email — no thanks-footnote should appear.
  \item Dave's slot has empty address — no small-italic line below.
  \item Bob's address spans two lines via \verb|\affilbreak|; spacing
        should be tight (not the airy default \verb|\\|).
  \item Institution ``Example University'' and location ``Yokohama...''
        appear between author block and date.
  \item \verb|\subtitle| and \verb|\keywords| are stored but NOT
        rendered on the title page; they should populate
        \texttt{pdfsubject} / \texttt{pdfkeywords} in the PDF (open the
        PDF info dialog to verify).
  \item Calls to \verb|\dedicatory|, \verb|\subjclass|,
        \verb|\setabstract|, \verb|\setacknowledgements| emit a
        \texttt{PackageWarning} at compile time but do not break the
        build, and produce no visible output.
\end{enumerate}

\section{Legacy single-call \texttt{\textbackslash author} smoke test}

The block above used \verb|\addauthor| four times. The legacy
single-call form \verb|\author{Alice and Bob}| is also accepted as
backward-compatible: it pushes one seq entry whose rendered string is
\textit{exactly} what was passed in. To verify that path, comment out
all \verb|\addauthor| lines and uncomment a single-author
\verb|\author{...}| call before \verb|\maketitle|.
